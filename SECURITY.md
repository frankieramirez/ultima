# Security policy

## Reporting a vulnerability

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/frankieramirez/ultima/security/advisories/new). Do not open a public issue or pull request for a security problem.

There is no public security email.

## What to expect

Ultima is maintained by one person. Reports get a best-effort response — read, assessed, and acted on as time allows — rather than a guaranteed timeline. If the report is valid, the fix and the advisory are coordinated privately before anything is published.

Please include enough detail to reproduce the issue: the affected component or package, what an attacker could do with it, and a minimal demonstration if you have one.
