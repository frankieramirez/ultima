# Meter

A static measurement built on Base UI's Meter, with one tone for the fill and the number.

## Install

```bash
npx shadcn add @ultima/meter
```

## Report meter

Compose `Label`, `Track`, `Indicator`, and `Value` for a compact report-style measurement. `tone` on `Root` colors the fill and the number together.

<Demo component={Report} source={reportSource} />

## Tones

`tone` is set once on `Root` and reaches `Indicator` and `Value` through a context private to the component. `neutral` is the default.

<Demo component={Tones} source={tonesSource} />

## Overriding one part

`Indicator` and `Value` each accept their own `tone`, which wins over the one `Root` provides. A neutral number under a colored bar is one extra prop.

<Demo component={Override} source={overrideSource} />

## Props

Only what Ultima adds. Everything else is Base UI's; see [Base UI's Meter](https://base-ui.com/react/components/meter) for the inherited surface.

| Part | Prop | Type | Default | Notes |
| --- | --- | --- | --- | --- |
| `Root` | `tone` | `'neutral' \| 'highlight' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` | Colors the fill and the number. |
| `Indicator` | `tone` | `'neutral' \| 'highlight' \| 'success' \| 'warning' \| 'danger'` | `Root`'s tone | Overrides the fill alone. |
| `Value` | `tone` | `'neutral' \| 'highlight' \| 'success' \| 'warning' \| 'danger'` | `Root`'s tone | Overrides the rendered number alone. |
| Every styled part | `style` | `StyleXStyles` | — | The style slot, merged last. There is no `className`. |
| Every part | `render` | `ReactElement \| function` | — | Base UI's render prop. |

`Indicator` and `Value` read the tone from `Root`. Rendered outside one they fall back to `neutral` rather than throwing.

## Accessibility

- **Name.** `Meter.Label` names the meter.
- **Focus ring.** None. A meter is not focusable.
- **Keyboard.** None. The value is static and exposed through the meter semantics.
