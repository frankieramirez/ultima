# Dropdown Menu

An action menu built on Base UI's Menu, including links, selection, groups, and submenus.

## Install

```bash
npx shadcn@4.21.4 add @ultima/dropdown-menu
```

## Features

The trigger slot must hold an Ultima Button or an element carrying its own focus ring. Icons belong in an item's content, and may come from any icon set in an [Icon](/components/icon); Ultima itself ships no icon dependency.

A shortcut is `DropdownMenu.Shortcut`, muted text at the row's trailing edge. In a checkbox or radio item it goes before the indicator, and the check keeps the outermost edge, so state stays in one column. A destructive action takes `tone="danger"` on `Item`: its label, icon and shortcut turn the danger ink, and its highlight the danger tint. Put it last, after a separator.

## Props

Only what Ultima adds. Every inherited part and prop is documented by [Base UI's Menu](https://base-ui.com/react/components/menu).

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `style` | `StyleXStyles` | — | Available on styled menu parts and merged last. There is no `className`. |
| `tone` | `'neutral' \| 'danger'` | `'neutral'` | On `Item`. `danger` marks a destructive action. |
| `render` | `ReactElement \| function` | — | Base UI's render prop. Trigger is an unstyled slot for a control with its own focus ring. |

`DropdownMenu.Shortcut` is a `<span>` with the style slot. Its text joins the item's accessible name, so when the app binds the keys, name them in `aria-keyshortcuts` on the item too.

## Accessibility

- **Name.** From the trigger text, or from `aria-label` on the trigger.
- **Focus ring.** On the element rendered into Trigger; menu items use a highlighted state instead.
- **Keyboard.** Base UI loops arrow-key navigation, supports typeahead, and closes the menu with Escape or Tab.
