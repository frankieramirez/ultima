# Badge

A small static label in three variants and six tones.

## Install

```bash
npx shadcn@4.21.4 add @ultima/badge
```

## Variants and tones

`subtle` annotates a surface with a tint. `outline` is the quietest: no fill, and a 0.5px edge in the tone's border color. The edge only decorates, because the words already carry the meaning. `solid` carries the most emphasis. Each variant supports all six tones.

<Demo component={Variants} source={variantsSource} />

## Status dot and icons

`dot` puts a 6px dot before the label, in the tone's solid color. On a `solid` badge the dot takes the label's color instead, so it doesn't vanish into the fill. A leading `Icon` sits 4px from the label the same way. A badge holding either gives up a step of inline padding, because a mark looks lighter than a word. The dot is decorative: the label still says the status.

## Props

Only what Ultima adds. Everything else is native; see MDN's [`span`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span) reference.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `variant` | `'subtle' \| 'outline' \| 'solid'` | `'subtle'` | Shape and emphasis. |
| `tone` | `'neutral' \| 'accent' \| 'highlight' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` | Color role, including its text or contrast color. |
| `dot` | `boolean` | `false` | A leading status dot, hidden from assistive technology. |
| `style` | `StyleXStyles` | — | The style slot, merged last. There is no `className`. |
| `render` | `ReactElement \| function` | — | Changes the root from its default `span`. |

## Accessibility

- **Name.** The Badge is a static `span` named by its text content.
- **Meaning.** Color never carries meaning alone. Pair every tone with text that says the status, as the examples do. The dot is `aria-hidden` and adds nothing to the name.
- **Focus and keyboard.** None. Badge is static.
