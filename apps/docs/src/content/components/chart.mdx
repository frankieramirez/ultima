# Chart

A figure that draws a [TanStack Charts](https://tanstack.com/charts) definition as SVG painted with Ultima's tokens, named by its caption. You write the chart in TanStack's grammar; `Chart` compiles it to a scene and draws the scene.

## Install

```bash
npx shadcn@4.21.4 add @ultima/chart
```

The item imports `@tanstack/charts`, so the install adds it to your dependencies. It is the one Ultima item that carries an engine, because a chart is the engine's output.

## Bar chart

`Chart.Root` takes a `definition`, which you build with `defineChart({ marks })` from `@tanstack/charts/scene` and a mark and scale from their own entries: `barY` from `@tanstack/charts/bar`, `scaleBand` from `@tanstack/charts/scales/band` and `scaleLinear` from `@tanstack/charts/scales/linear`. Ultima neither wraps nor re-exports the grammar, so TanStack's reference is the reference for marks, scales, axes and tick formats. Keep the definition stable between renders, at module scope or in a `useMemo`: `Chart.Root` compiles it again whenever it changes.

Give the root exactly one of `height`, in CSS pixels, or `aspectRatio`, width over height. Neither has a default, and the type accepts one or the other, never both. The plot fills the width it is given, and the root compiles the definition again at the plot's measured size whenever that size changes.

## Line chart with a legend

`lineY` from `@tanstack/charts/line` draws one line per color group. Give it one row per x value and series, and name the series field as its `color` channel. `points: true` adds a dot at each observation. An ordered x takes `scalePoint` from `@tanstack/charts/scales/point`.

`Chart.Legend` lists the color groups in the order the chart colors them, each with its swatch and its name. Place it inside `Chart.Root`, after the plot. It is a plain list: it takes no focus and toggles nothing.

<Demo component={Line} source={lineSource} fill />

## Stacked area chart

`stackRowsY` from `@tanstack/charts/transform/stack` gives each row its band's base, `y1`, and top, `y2`. `areaY` from `@tanstack/charts/area` draws one band per group from them, with the stack's `z` as its `color`. Bands fill solid, so they stack and never overlap. Series you compare against one baseline rather than add up belong in a line chart.

## Data table in a disclosure

Every chart pairs with a `Table` of the same rows. Where a table beside the chart would crowd the layout, put it in a `Collapsible` under the plot, as Dashboard 01 does. A single series needs no legend, because the caption names it.

## What Chart draws, and what it ignores

`Chart.Plot` walks the compiled scene and draws its seven node kinds as SVG elements painted from tokens: `group`, `rule`, `rect`, `polyline`, `area`, `dot` and `label`.

- **Marks** take `--ult-color-series-1` through `-6` by their group's position in the color domain. Bars, area bands and dots fill solid in their series color, and a line is a 2px stroke in it. A dot keeps the radius the scene gives it, because a dot's size can be data. Lines and bands run straight between their points.
- **Guides.** Gridlines and the axis baseline take `--ult-color-border`. Tick labels take `--ult-color-text-subtle`, and axis titles and band labels `--ult-color-text-muted`, all at `--ult-text-3`. Labels are measured with the plot's own font, so the scene's layout matches the text you see.
- **The legend.** Swatches take the series token and labels `--ult-color-text-muted`, at `--ult-text-3`.

The scene's own paint strings and `ts-chart` class names never reach the page, and no `--ts-chart-*` variable is set or read, so a mark's own `stroke`, `fill`, opacity or stroke width is ignored. So are the definition's `theme`, `tooltip`, `keyboard`, `focusRing` and `svgAnimation` options, because Chart owns each of them.

## Other marks

Any mark that compiles to the seven node kinds draws through the same renderer, with no demo of its own: `dot` from `@tanstack/charts/dot` for a scatter plot, sized by its `r` channel; `ruleX` and `ruleY` from `/rule` for reference lines; `tickX` and `tickY` from `/tick`; `rect` and `cell` from `/rect`; `bandX` and `bandY` from `/band`; `text` from `/text`; and the horizontal `barX` and `lineX`.

## Series colors

There are six series tokens, and a seventh group starts again at series 1, so two groups share a color. Fold small groups into an "Other" group rather than let colors repeat.

A chart whose groups carry meaning, such as a series that should read as danger, re-points `--ult-color-series-<n>` on its `Root` with a `stylex.createTheme` passed through `style`. The marks and the legend inside the root both follow it.

```tsx
import * as stylex from '@stylexjs/stylex';
import { color } from '@ultima/tokens/tokens.stylex';

// Errors are the second color group in the definition.
const errorsInDanger = stylex.createTheme(color, {
  '--ult-color-series-2': color['--ult-color-danger'],
});

<Chart.Root definition={definition} height={240} style={errorsInDanger}>
  <Chart.Caption>Requests and errors</Chart.Caption>
  <Chart.Plot />
  <Chart.Legend />
</Chart.Root>;
```

## Props

| Part | Prop | Type | Default | Notes |
| --- | --- | --- | --- | --- |
| `Root` | `definition` | `ChartDefinition` | — | Required. A `defineChart({ marks })` result. |
| `Root` | `height` | `number` | — | CSS pixels. Exactly one of `height` or `aspectRatio`, written inline on the plot as its one size declaration. |
| `Root` | `aspectRatio` | `number` | — | Width over height. Exactly one of `height` or `aspectRatio`. |
| `Root`, `Caption`, `Legend` | `render` | `ReactElement \| function` | — | Changes the part's element from its default `figure`, `figcaption` or `ul`. |
| Every part | `style` | `StyleXStyles` | — | The style slot, merged last. There is no `className`. |

`Chart.Plot` renders a fixed `svg` and takes no `render`. `Chart.Legend` takes no children: its items come from the chart's color groups.

## Accessibility

- **Role and name.** `Chart.Root` is a `figure` named by `Chart.Caption`, which is required. `Chart.Plot` is an `svg` with `role="img"` and `aria-roledescription="chart"`, labelled by the same caption through `aria-labelledby`.
- **The data equivalent.** Pair every chart with a `Table` holding the same rows, beside it or in a `Collapsible` disclosure. A visually hidden table is not an equivalent.
- **Color alone.** The legend names each series in text and its swatches are `aria-hidden`, and the table carries every value, so no reading depends on a mark's color.
- **Motion.** Nothing animates, and the definition's `svgAnimation` is ignored.
