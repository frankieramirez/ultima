# Input

A text input built on Base UI's Input, with the three shared control sizes and consumer-owned labeling.

## Install

```bash
npx shadcn@4.21.4 add @ultima/input
```

## Sizes

`sm`, `md`, and `lg` use Ultima's three control heights. `md` is the default. Text is 14px at `sm` and `md` and 16px at `lg`, and rises to 16px on touch screens so iOS does not zoom into the field on focus.

## Labels

Prefer a visible `<label htmlFor>` when the interface has one. `aria-label` names a control whose purpose is already visible from context; `aria-labelledby` can point to existing visible text.

## Validation, read-only and disabled state

Standalone, validation state belongs to the consumer's `aria-invalid`; connect the error text with `aria-describedby`. Inside a `Field.Root`, Base UI owns `aria-invalid`, `data-invalid`, and the description merge — Input needs no new prop. The danger border matches `':is([aria-invalid="true"], [data-invalid])'`, so a control that is disabled while invalid keeps the border. A read-only field keeps the bright fill and the normal ink, since its value is still there to read, select and submit, and gives up only what says "type here": the 3:1 edge quiets, hover stays off and the caret is hidden. A disabled field also takes the sunken fill and drops its text to the disabled ink, with no fading.

Prefer Field when you need a label, description, and error wired together. See the Field page for form integration.

## Props

Only what Ultima adds. Everything else is Base UI's; see [Base UI's Input](https://base-ui.com/react/components/input) for the inherited surface.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `size` | `'sm' \| 'md' \| 'lg'` | `'md'` | Control height, padding, and text step. |
| `style` | `StyleXStyles` | — | The style slot, merged last. There is no `className`. |
| `render` | `ReactElement \| function` | — | Base UI's render prop. |

## Accessibility

- **Name.** A consumer `<label htmlFor>`, `aria-label`, or `aria-labelledby`.
- **Focus ring.** On the input root, drawn on `:focus-visible` only.
- **Keyboard.** Native input behavior, unchanged.
