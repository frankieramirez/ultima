# Code

Monospaced code, inline in a sentence or as a wrapping block.

## Install

```bash
npx shadcn add @ultima/code
```

## Inline

The default variant renders a native `code` element in the surrounding sentence.

## Kbd

A `<kbd>` is Code rendered as the user-input element, `<Code render={<kbd />}>`. `code.tsx` already takes `render` through `useRender`, so the recipe needs no component change and there is no `@ultima/kbd` item to install.

Component dependency: `code`.

The documented states are a single key and a combination — one `<kbd>` per key, joined by `+` text, rather than one element around the whole chord.

## Typography

Typography is the prose mapping, a recipe rather than a component: there is no `@ultima/typography` item and no file to install. It is the shape the docs' own `Prose` proves — headings through `h3`, paragraphs, lists, links, and blockquotes are token styles, which is page layout's own work, and the rest delegates to the catalogue.

Component dependencies: `code`, `separator`, `table`, `scroll-area`.

```bash
npx shadcn add @ultima/code @ultima/separator @ultima/table @ultima/scroll-area
```

`code` and `pre` delegate to `Code`, inline and `block`; syntax highlighting is your own pipeline. `hr` delegates to `Separator`, because a hairline is paint that page layout cannot write. `table`, `th`, and `td` delegate to `Table` inside a `ScrollArea`, because a GFM table has no caption to name a `Table.Scroll` region from. The documented state is the element set itself, rendered end to end in the demo.

## Props

Only what Ultima adds. Everything else is native; see MDN's [`code`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/code) and [`pre`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/pre) references.

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `variant` | `'inline' \| 'block'` | `'inline'` | Chooses `code` or `pre` with a `code` child. |
| `style` | `StyleXStyles` | — | The style slot, merged last. There is no `className`. |
| `render` | `ReactElement \| function` | — | Changes the root element. |

## Accessibility

- **Elements and name.** Native `code`, or `pre` with a `code` child for a block; its content is the accessible text.
- **Focus and keyboard.** None. Blocks wrap long lines, so they are not scroll regions and need no `tabIndex`.
