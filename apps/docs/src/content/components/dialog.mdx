# Dialog

A modal surface built on Base UI's Dialog, with a backdrop, managed focus, and an accessible title.

## Install

```bash
npx shadcn add @ultima/dialog
```

## Basic

The trigger and close slots must hold an Ultima Button or an element carrying its own focus ring. The canonical close action uses a text label.

## Close icon

Ultima ships no close glyph and no icon dependency. Supply a glyph from any icon set and give an icon-only close control an `aria-label`.

## Visually hidden title

A `Dialog.Title` is always rendered. When the design has no visible heading, hide the title through its `style` slot rather than omitting it.

<Demo component={HiddenTitle} source={hiddenTitleSource} />

`modal` remains [Base UI's](https://base-ui.com/react/components/dialog) default. Ultima does not set `keepMounted`; pass it when the closed dialog should remain in the DOM.

`Dialog.Backdrop` does not render when the root is nested, and an app shell is enough to make it nested. Base UI counts any surrounding dialog root, and [Sidebar](/components/sidebar) is one: `Sidebar.Root` wraps its children in a `Dialog.Root` for the mobile menu, so a dialog anywhere inside an Ultima app shell loses its scrim. Pass `forceRender`, which every demo on this page does. Leave it off for a dialog genuinely stacked on another dialog, where the one scrim underneath is the point. The scrim itself is `--ult-color-surface-overlay` over a `--ult-filter-backdrop` blur.

## Sheet

A sheet is a Dialog anchored to an edge of the viewport instead of centred in it. It is a recipe rather than a component: there is no `@ultima/sheet` item and no file to install, because every part it needs is already Dialog's and the difference is `style` overrides written at the call site.

Component dependencies: `dialog` and `button`.

```bash
npx shadcn add @ultima/dialog @ultima/button
```

`Dialog.Viewport` zeroes its padding and swaps `placeItems: center` for the edge. `Dialog.Popup` drops its radius and its measure cap, keeps a hairline on the side facing the page, and slides in from its edge over `--ult-motion-base` in place of the shared `scale(0.98)`. The four edges are physical rather than logical, because CSS has no logical transform.

**The override names the resting, starting, and ending transforms, or Dialog's scale survives underneath the slide.** `Dialog.Popup` carries `scale(0.98)` on both `[data-starting-style]` and `[data-ending-style]`, and StyleX merges a property one condition at a time. An override that sets only the resting transform leaves the scale in place for the other two states, and the panel scales while it travels.

<Demo component={Sheet} source={sheetSource} />

[Sidebar](/components/sidebar)'s mobile menu is this same variation with one edge hard-coded, and it keeps its own private copy rather than consuming the recipe: a recipe has no importable unit. It is also the `aria-label` case rather than the `Dialog.Title` case above, because a navigation panel has no visible heading.

### Sheet or Drawer

The test is a capability rather than a taste, and Base UI states it in its own words: a panel that slides in from an edge and needs no gesture support is a positioned Dialog, which is what a sheet is. Reach for [Drawer](/components/drawer) when the panel needs swipe-to-dismiss, swipe-to-open, snap points, or the Android back gesture. **The last of those decides it**: that gesture runs on `CloseWatcher`, which Drawer mounts and which appears nowhere in Dialog, so a sheet can be made to look identical and can never answer it.

## Props

Only what Ultima adds. Every inherited part and prop is documented by [Base UI's Dialog](https://base-ui.com/react/components/dialog).

| Prop | Type | Default | Notes |
| --- | --- | --- | --- |
| `style` | `StyleXStyles` | — | Available on the styled Viewport, Backdrop, Popup, Title, and Description parts; merged last. There is no `className`. |
| `render` | `ReactElement \| function` | — | Base UI's render prop. Trigger and Close are unstyled slots for a control with its own focus ring. |

## Accessibility

- **Name.** From `Dialog.Title`, which is always rendered. `Dialog.Description` is optional.
- **Focus ring.** On Close and any focusable content, supplied by the element rendered into each slot.
- **Keyboard.** Base UI loops Tab inside the modal, closes it with Escape, and returns focus to the trigger.
